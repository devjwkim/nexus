# Boot Prompt

This project is a Claude Code task management template.

## Initial Setup

**Required**: `/output-style buffer-style`

## Key Features

- `~!` Start task
- `~@` Complete task (auto-calls deployer)
- `~#` Run tests (auto-calls tester)
- Auto history management
- Auto SETTINGS load

## Workflow

1. `~! task description` → Start task, generate TODO
2. Work in progress...
3. `~#` → Run tests (optional)
4. `~@` → Complete and auto-deploy

## Rules

- Concise and practical
- Avoid unnecessary abstraction
